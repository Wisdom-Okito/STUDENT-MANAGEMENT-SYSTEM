# STUDENT MANAGEMENT SYSTEM.

## Project Description.
### The Student Management System is a Java application designed to make it easier to manage student records.
### The system allows you to search,delete,update and view the students information through a simple menu-driven interface.
### This project was developed by a beginner-level Java Backend project to demonstrate the practical use of Java programming concepts.

## Project Objectives.
### The main objectives of this project are to:
- Add new student records.
- view existing student records.
- search for students using their ID.
- update student information. 
- Delete student records.
- Demonstrate CRUD operations using Java.
- Apply basic programming concepts to real-world problem.

## Problem Statement.
### Manage students records manually can be time-consuming and its may results in errors, duplicate records, loss of information, differently in retrieving records or updating records.

## Solution.
### The Student Management System is a menu-driven application where users can perform different operations on the students records.
1. Add students
2. view students
3. search students
4. update students
5. delete students
6. Exit

## CRUD Operations.
-C = create: Add new student records to the system.

-R = read: View existing student records in the system.

-U = update: Modify existing student records in the system.

-D = delete: Remove student records from the system.
